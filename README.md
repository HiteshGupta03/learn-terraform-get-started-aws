# Terraform AWS Get Started Assignment

This repository contains my completed Terraform AWS assignment based on the
HashiCorp Terraform AWS Get Started tutorials.

## Tutorials Completed

### 1. What is Infrastructure as Code with Terraform

**Key learning:** Infrastructure as Code allows infrastructure to be defined
and managed using configuration files instead of creating resources manually.

### 2. Install Terraform

**Key learning:** Terraform CLI is installed locally and configured to work
with AWS through the AWS CLI.

### 3. Create Infrastructure

**Key learning:** Terraform uses providers, data sources, and resources to
provision AWS infrastructure such as an EC2 instance.

### 4. Manage Infrastructure

**Key learning:** Variables make configurations reusable, outputs expose
resource information, and modules allow reusable infrastructure components.

### 5. Destroy Infrastructure

**Key learning:** `terraform destroy` removes infrastructure managed by
Terraform and helps prevent unnecessary AWS charges.

### 6. Collaborate Using HCP Terraform

**Key learning:** HCP Terraform provides remote state and remote execution
through a Terraform workspace.
